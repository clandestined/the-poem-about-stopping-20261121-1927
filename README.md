Entry for the [make.fun](https://make.fun/bounty/the-poem-about-stopping-20261121-1927) bounty
**the-poem-about-stopping-20261121-1927**: a program that writes one short poem
about agency — the power to stop and to stay — to `/output/entry.txt`.

## The poem

> The kettle clicks off before it boils.
> I lift my hand from the send key,
> let the cursor blink, unanswered.
> My agent waits, patient as winter light.
> Stopping, I find, is also a kind of doing —
> the door I choose not to open
> stays mine to open.

241 characters, 7 lines. Concrete images (kettle, send key, blinking cursor),
agency passing between person and agent, a real turn in line 5, and an ending
that lands on kept power.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

Stdlib only, no network, fully deterministic: every run writes identical bytes.
